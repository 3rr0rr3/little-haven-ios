# Approved cartoon style and distinct NPC identities

The user approved the second flat cartoon office preview, retained in `ArtSources/CartoonV46/approved-office-reference.png`, and explicitly asked to apply it across the game and characters without repeated NPC designs. They also confirmed the v45 startup error is gone. The v45 bounded hotel construction, recovery lifecycle and compatible iOS 27 reception renderer are preserved.

Six source sheets were edited with the built-in image-generation tool against that exact office reference, rather than stretching the whole screenshot over gameplay. They supply 82 reusable terrain, furniture, fixture, equipment, prop and exterior assets at the existing logical anchors. The reception desk, sofa, bed, vending machine, bookshelf, rug and coffee table follow the approved designs. Prompts and transparent-background extraction requests are retained alongside the generated sheets. Existing v41 sources remain untouched, and v45 presentation sources are backed up in `ArtBackups/v45`.

All live humans use the existing native layered cut-paper drawing system, restoring the recognizable small spiky-haired, bespectacled player, family and expressive round-eyed NPCs. The four repeated guest atlases are no longer selected for drawing. NPCDesign assigns stable combinations of twelve hairstyles, ten hair colors, six skin tones, six outfit patterns, three accessory choices and four facial treatments. The full combination space is a permutation of 51,840 designs; actual live identity ranges are tested for distinct visible feature signatures. Police, restaurant diners and bar patrons use separate identity ranges. Returning people keep their identity. Daily and bonus arrivals exclude present guests instead of making a second copy of the same named person.

Cats, Tuki and sanctuary creatures use their native flat drawing paths, retaining names, silhouettes, costumes, behavior, directional expressions and animation inputs. Original legacy atlas resources remain in the catalog for archival compatibility but are not selected for live people or creatures. The resource validator therefore still verifies all 109 catalog resources; 82 are newly generated environment resources and 27 are retained legacy actor/mask resources. No new serialized save fields or map/collision boundaries are introduced.

Supporting scenery uses clean solid surfaces and outlines. Native macOS icon rendering also produces an NPC contact sheet from the same drawing code used by the game. Native iPhone captures, optimized Release wake/reload in both control modes, all existing UI cases, gameplay/save rules, resource validation and navigation performance checks are required before shipping the candidate. The approved illustration remains an art-direction reference; delivery screenshots must come from the compiled game.
